✨ FEATURES

What This System Does

Every feature backed by real data from detectors and the RL agent — nothing hardcoded.

🆕 UPGRADED 🧠
DQN Reinforcement Learning
The agent learns optimal signal policies from experience using a 256→256→128 deep Q-network with experience replay, target networks, and Huber loss.
🚦
Adaptive Signal Control
Green time is dynamically computed from lane density, accumulated wait time, and weather. No more fixed 30-second timers.
🚑
Ambulance Priority Override
YOLOv8 detects ambulances at ≥70% confidence. The current cycle is immediately interrupted and green is given to the emergency lane for 15 seconds.
🆕 NEW 🚶
Pedestrian Safety Module
COCO class 0 detection identifies pedestrians in each lane. Pedestrian presence triggers a soft override feeding directly into the RL state vector.
🆕 NEW 🌦️
Weather-Aware Timing
Rain and fog conditions extend green times automatically. The weather factor (0–1.0) is a dedicated dimension in the 18-D RL state vector.
🆕 NEW 📊
Live RL Training Monitor
Dedicated page with live reward curve, ε-decay chart, Q-network loss, total wait time, and per-lane Q-value bars — all from real agent data.
🛡️
Lane Starvation Guard
Any lane skipped 4+ consecutive cycles gets a forced green. This prevents the RL agent from ignoring low-density lanes indefinitely.
🗃️
SQLite Cycle Logging
Every signal cycle logs: vehicle counts, pedestrians, ambulances, green time, and the decision mode (exploit/explore/override) to the database.
